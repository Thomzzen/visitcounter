GitHub connection

First time here? How to get a token
  1. Open github.com/settings/personal-access-tokens/new (log in if it asks)
  2. Give it any name, e.g. "Gadget Weekly admin"
  3. Under "Repository access" choose "Only select repositories" → pick Thomzzen/visitcounter
  4. Under "Permissions" → "Repository permissions", set Contents to Read and write (leave everything else as-is)
  5. Click "Generate token" at the bottom, copy the token it shows you (starts with github_pat_)
  6. Paste it into the field above and click "Save token"

The token is stored only in this browser (never sent anywhere except api.github.com) and only has access to this one repository. Treat it like a password. Click "Disconnect" if you're on a shared computer.
