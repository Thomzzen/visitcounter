Security

Nothing secret lives in this page anymore — no password hash, no GitHub token. Both are stored only as secrets on Cloudflare and checked on the server. To change either:

  • Go to the Cloudflare dashboard → Workers & Pages → your worker → Settings → Variables and Secrets.
  • Edit ADMIN_PASSWORD to rotate the password, or GITHUB_TOKEN to rotate the token. Use a real passphrase (three or four random words) for the password.
  • Make sure the GitHub token is a fine-grained token scoped to only this repository with only Contents: Read and write, and give it an expiration date.
